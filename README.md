# Expense Tracker – Java Project

## 📌 Project Overview
Expense Tracker is a console-based Java application that helps users manage their daily expenses efficiently. It allows users to add, view, update, delete, and analyze their expenses.

## 🚀 Features
- Add Expense
- View All Expenses
- Calculate Total Expenses
- Delete Expense
- Update Expense
- Category-wise Expense Summary
- Search Expenses by Category
- Find Highest and Lowest Expenses

## 🛠️ Technologies Used
- Java
- Object-Oriented Programming (OOP)
- Collections Framework
- File Handling
- VS Code
- Git and GitHub

## ⚙️ How to Run the Project

1. Clone or download the repository.
2. Open the project in VS Code or any Java IDE.
3. Make sure Java JDK is installed.
4. Open `Main.java`.
5. Run the application.
6. Select the required option from the menu.
