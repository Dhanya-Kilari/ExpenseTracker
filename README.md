# 💰 Expense Tracker - Java Project

## 📌 Project Overview
Expense Tracker is a console-based Java application that helps users manage their daily expenses efficiently. It allows users to add, view, update, delete, search, and analyze expenses with date-wise tracking and summaries.

## ✨ Features
- Add Expense with Category, Amount, and Date
- View All Expenses
- Calculate Total Expenses
- Delete Expense
- Update Expense Details
- Category-wise Expense Summary
- Search Expenses by Category
- Find Highest and Lowest Expenses
- Daily Expense Summary
- Monthly Expense Summary
- Yearly Expense Summary

## ▶️ How to Run the Project
1. Clone or download the repository.
2. Open the project in VS Code or any Java IDE.
3. Ensure Java JDK is installed.
4. Run `Main.java`.
5. Select the required option from the menu.
